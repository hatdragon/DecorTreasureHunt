# Decor Treasure Hunt

**Decor Treasure Hunt** is a World of Warcraft addon that helps players find Neighborhood Decor Treasure Hunt clues and waypoints for both Alliance and Horde.

---

## Features

- **Faction Tabs** — Toggle between Alliance and Horde treasure locations
- **Search** — Filter riddles by text or item name in real time
- **Waypoint Integration** — Click any treasure to set a waypoint via TomTom or WoW's built-in system
- **Scrollable List** — Browse all 56 riddle locations per faction with coordinates
- **Resizable Window** — Drag to move, resize from the corner

---

## Usage

Open the tracker with:

```
/dth
```

Click any riddle entry to set a waypoint to its location.

---

## Installation

Download and extract into:

```
World of Warcraft/_retail_/Interface/AddOns/DecorTreasureHunt
```

Restart WoW or `/reload`.

---

## Dependencies

- **Optional:** [TomTom](https://www.curseforge.com/wow/addons/tomtom) for enhanced waypoints (falls back to built-in waypoints if not installed)
